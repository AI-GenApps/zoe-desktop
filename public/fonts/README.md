# Zoe Agent fonts

Downloaded unchanged on 2026-10-18 from the official Google Fonts CSS service and its Google-hosted font files. Both families use the SIL Open Font License 1.1; their complete licenses are included alongside the fonts.

| Local file | Family | Style and supported weight | Size |
| --- | --- | --- | --- |
| `syne-latin-700.woff2` | Syne | Normal, static **700** (Bold) | 14,072 bytes |
| `geist-latin.woff2` | Geist | Normal, variable **100–900** | 29,400 bytes |

These are the Google Fonts **Latin** subsets. They include common Latin letters, punctuation and symbols, rather than every script supported by the full families. Keep system-font fallbacks for other characters. Register Syne with weight `700` and Geist with the range `100 900`; neither file supplies italics.

## Official sources

- Syne CSS: <https://fonts.googleapis.com/css2?family=Syne:wght@700&display=swap>
- Syne font (the CSS `latin` block, version 24): <https://fonts.gstatic.com/s/syne/v24/8vIS7w4qzmVxsWxjBZRjr0FKM_3fvg6jTY8.woff2>
- Syne license, saved as `syne-OFL.txt`: <https://raw.githubusercontent.com/google/fonts/main/ofl/syne/OFL.txt>
- Geist CSS: <https://fonts.googleapis.com/css2?family=Geist:wght@100..900&display=swap>
- Geist font (the CSS `latin` block, version 5): <https://fonts.gstatic.com/s/geist/v5/gyByhwUxId8gMEwcGFU.woff2>
- Geist license, saved as `geist-OFL.txt`: <https://raw.githubusercontent.com/google/fonts/main/ofl/geist/OFL.txt>

The CSS was requested with a modern Chrome user agent to select WOFF2 output. `file` identified both downloads as WOFF2, and `fc-scan` identified Syne Bold and the Geist variable family.
