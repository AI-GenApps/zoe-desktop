# Desktop release signing checklist

The release workflow uses GitHub-hosted macOS and Windows runners. Configure
these Actions secrets before running a signed release. Never commit the source
certificate files, private keys, or passwords.

| Secret | Description |
| --- | --- |
| `TAURI_SIGNING_PRIVATE_KEY` | Private key generated by `pnpm tauri signer generate`; used for updater archive signatures. |
| `TAURI_SIGNING_PRIVATE_KEY_PASSWORD` | Password for the Tauri updater signing key. |
| `APPLE_CERT_P12_BASE64` | Base64-encoded Developer ID Application `.p12` export. |
| `APPLE_CERT_PASSWORD` | Password used for the `.p12` export. |
| `APPLE_ID` | Apple ID used by `notarytool`. |
| `APPLE_TEAM_ID` | Apple Developer Team ID. |
| `APPLE_APP_SPECIFIC_PASSWORD` | App-specific password for Apple notarization. |
| `WINDOWS_CERT_PFX_BASE64` | Base64-encoded Windows OV code-signing `.pfx` export. |
| `WINDOWS_CERT_PASSWORD` | Password used for the `.pfx` export. |

## Prepare the signing material

1. Export the Apple Developer ID Application certificate and its private key
   from Keychain Access as a password-protected `.p12` file. Encode it as one
   line, for example `base64 -i DeveloperID.p12`.
2. Obtain an OV Windows code-signing certificate, export it with its private
   key as a password-protected `.pfx`, and encode it as one line. On GNU/Linux,
   use `base64 -w0 DeveloperID.pfx`; PowerShell can use
   `[Convert]::ToBase64String([IO.File]::ReadAllBytes("DeveloperID.pfx"))`.
3. Generate or retrieve the Tauri updater key pair. Keep the private key in
   the GitHub secret and keep the public key in `tauri.conf.json`.
4. Add the nine values in the repository Settings → Secrets and variables →
   Actions. The PR workflow does not reference any of them.

The release workflow imports the Apple certificate into a temporary keychain,
decodes the Windows certificate into the runner temp directory, and removes
the temporary files after the build. It signs Windows binaries with
`signtool.exe`, notarizes the macOS bundle with Apple `notarytool`, and signs
Tauri updater archives with the Tauri private key.

## Rotation

When a certificate or password changes, export a replacement file, re-encode
it, and update only the corresponding GitHub secret. No workflow change is
needed. Revoke expired certificates at the issuing provider and confirm a
manual release from `main` succeeds before the next production tag.
